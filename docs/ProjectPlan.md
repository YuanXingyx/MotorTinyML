# MotorTinyML 项目计划

## 基本信息

- 项目名称：MotorTinyML
- 项目周期：2026-08-01 至 2026-08-31
- 当前阶段：Sprint 0
- 项目角色：Tech Lead、Project Engineer

## 项目目标

在技术负责人确定的范围和架构下，完成 MotorTinyML 嵌入式 AI 项目的开发、测试、文档与交付工作。

## 执行原则

1. 项目工程师严格执行技术负责人的计划和架构决策。
2. 不擅自修改项目范围或重新设计架构。
3. 需求不明确时，先确认再实施。
4. 开发任务必须包含测试、文档、开发日志和 Git 提交建议。
5. 项目文档应与代码及项目状态保持同步。
