# 完成定义

任务只有满足所有适用条件后，才能标记为完成。

## 需求

- 任务范围和验收标准明确。
- 实现符合技术负责人的项目计划和架构。
- 未擅自扩大范围或引入未经批准的设计。

## 实现

- 代码或文档结构清晰、命名一致。
- 不存在已知的无关改动。
- 配置与生成产物得到正确管理。

## 测试

- 已执行适用的自动化测试。
- 已执行必要的静态检查或构建检查。
- 手动验证步骤及结果已记录。
- 已知限制和失败项已记录。

## 文档

- README 与项目当前状态一致。
- 架构、接口、部署及测试文档按需更新。
- DevelopmentLog 和 TODO 已更新。
- CHANGELOG 已更新；若项目尚未建立 CHANGELOG，则在对应任务中创建。

## Git

- 变更范围已复核。
- Commit Message 符合 Git 规范。
- 未提交密钥、临时文件或非必要构建产物。

## 验收

- 所有验收标准均已满足。
- 阻塞项已解决或明确记录。
- 交付物可由其他团队成员复现和检查。
