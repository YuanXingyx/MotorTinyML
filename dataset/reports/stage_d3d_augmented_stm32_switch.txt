MotorTinyML Stage D-3D Augmented STM32 Switch
==============================================

Active model
------------
The STM32 realtime path now uses:

- tiny_classifier_3class_aug.c/.h
- tiny_classifier_3class_aug_params.c/.h

Class mapping remains 0=normal, 1=rotor_unbalance, 2=overload.
The previous tiny_classifier_3class files remain in the repository for
rollback and were not deleted.

Preserved behavior
------------------
- 21 statistical features and 200x3 windows
- ADXL345 path and 200 Hz sampling
- Motor_SetSpeed(60) and PWM
- STOPPED threshold 4000
- five-window majority vote
- OLED layout and final device states
- UART MOTION, CLASS, CLASS_VOTE, and DEVICE_STATE output
