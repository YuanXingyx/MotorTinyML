Build/resource verification
---------------------------
The STM32F103 Debug ELF was generated with the Stage C-6 changes. The IDE
make wrapper returned host-side `Error -1` after producing the ELF; no compiler
diagnostic or linker overflow was reported, and the ELF was inspected directly.

`arm-none-eabi-size`:

- text: 22048 bytes
- data: 96 bytes
- bss: 3360 bytes
- total: 25504 bytes

Flash estimate (text + data): 22144 bytes.
The static `inference_window[200][3]` accounts for 1200 bytes of RAM. The
remaining `.bss` includes existing firmware state and classifier statistics.
The ELF contains TinyClassifier symbols and no `model_inference`, `tflite`,
`tflm`, or `Model_Init` symbols; the Stage C-6 build is therefore fully
detached from the TFLM runtime.
