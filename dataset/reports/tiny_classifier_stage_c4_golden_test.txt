Test contract
-------------
Four Stage C-2 cases are used without reselection: normal, rotor_unbalance,
mechanical_looseness and overload. Each case executes
TinyClassifier_ExtractFeatures() and TinyClassifier_Predict() once at startup.
No real-time ADXL345 window, PWM control or continuous loop is used.
Feature tolerance: 1e-3. Score tolerance: 1e-3. Class id must match exactly.
UART reports case, expected/predicted class, feature max difference, scores,
expected scores and PASS/FAIL. Scores are printed as integer values multiplied
by 1000 to avoid requiring embedded printf floating-point support.
