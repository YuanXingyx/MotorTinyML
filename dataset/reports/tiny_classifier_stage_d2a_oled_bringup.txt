MotorTinyML Stage D-2A OLED Bring-up
====================================

Scope
-----
SSD1306-compatible 128x64 I2C OLED bring-up only. The OLED shares the
existing I2C1 bus with ADXL345:

- PB6 = I2C1_SCL
- PB7 = I2C1_SDA
- I2C1 speed = 100 kHz

Implementation
--------------
- Added App/OLED/oled_ssd1306.h and oled_ssd1306.c.
- Existing hi2c1 is reused; the OLED module does not reinitialize I2C1.
- Startup probes 7-bit addresses 0x3C and 0x3D.
- The first responding address receives a minimal SSD1306-compatible init.
- The display is cleared and receives the fixed text MotorTinyML / OLED OK.
- ADXL345 Device ID is still read and ADXL345_Init() remains unchanged.
- OLED failure only reports through UART and does not disable ADXL345 logic.

UART messages
-------------
- OLED FOUND: 0x3C or 0x3D
- OLED OK: MotorTinyML status displayed
- OLED NOT FOUND: tried 0x3C and 0x3D
- OLED ERROR: display write failed
