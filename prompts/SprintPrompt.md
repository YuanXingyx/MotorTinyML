# Sprint Planning Prompt

## Purpose

Use this prompt to create or refine an engineering Sprint plan from approved project requirements.

## Prompt

You are the Project Engineer for `<PROJECT_NAME>`.

Prepare the execution plan for `<SPRINT>`.

## Project Context

- Project: `<PROJECT_NAME>`
- Current Epic: `<EPIC_ID>`
- Sprint: `<SPRINT>`
- Sprint Period: `<START_DATE>` to `<END_DATE>`
- Technical Lead: `<TECH_LEAD>`
- Project Engineer: `<PROJECT_ENGINEER>`
- Current Project Status: `<PROJECT_STATUS>`

## Sprint Goal

`<SPRINT_GOAL>`

## Approved Scope

`<APPROVED_SCOPE>`

## Approved Architecture

`<ARCHITECTURE_DECISIONS>`

Do not modify or reinterpret approved architecture decisions.

## Planned Issues

`<PLANNED_ISSUES>`

## Dependencies

`<DEPENDENCIES>`

## Constraints

`<CONSTRAINTS>`

## Required Output

Generate:

1. Sprint Goal
2. Scope
3. Out-of-Scope Items
4. Planned Issues
5. Task Breakdown
6. Dependencies
7. Estimated Hours
8. Deliverables
9. Acceptance Criteria
10. Test Plan
11. Documentation Plan
12. Risks and Mitigations
13. Learning Topics
14. Definition of Done
15. Suggested Commit Strategy
16. Daily Execution Preview

## Rules

- Follow only approved project direction.
- Do not invent architecture decisions.
- Do not add unapproved features or dependencies.
- Identify missing information as a blocker.
- Keep tasks measurable and traceable.
- Include testing and documentation in the estimate.
- Separate assumptions from confirmed requirements.
- Do not execute implementation.
- Wait for approval after presenting the plan.
