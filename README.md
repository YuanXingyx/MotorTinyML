# MotorTinyML

MotorTinyML 是一个面向电机状态监测的嵌入式 AI 项目，目标是在资源受限的嵌入式平台上完成数据采集、模型训练、模型部署与设备端推理验证。

## 项目周期

2026-08-01 至 2026-08-31

## 目录结构

- `firmware/`：嵌入式固件
- `python/`：数据处理、训练与辅助工具
- `dataset/`：数据集及其说明
- `models/`：训练模型与部署模型
- `docs/`：项目计划、架构和开发文档
- `hardware/`：硬件设计资料与接口说明
- `prompts/`：AI 辅助开发的通用 Prompt Library

## 当前状态

Sprint 0：项目初始化。
